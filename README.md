## 🌱 关于惠农星球

惠农星球不只是一个游戏。

它是一个实验——用游戏化的方式，打通农业产业链的每一个环节。

从一粒种子开始：
- 你去种地，感受作物从破土到成熟的真实周期
- 你去收获，把原料送进加工台，变成产品
- 你去交易，在市场中决定什么时候卖、卖多少
- 你去积累，学习真实的农业知识，兑换真实的回报

这不是"点点点收菜"的休闲游戏。
这是一套完整的农业经营模拟。

---

## 🎯 五位一体

**游戏 × 知识 × 电商 × 助农 × 品牌**

五位不是并列的，是一层一层叠上去的：

1. **游戏**——好玩的经营模拟，是底座
2. **知识**——玩游戏也能学到真东西
3. **电商**——游戏里的积分，可以兑换实物
4. **助农**——做大了，农产品可以从这里出去
5. **品牌**——让真正好的农业品牌，被更多人知道

每一步都不急，但每一步都在往前走。

## 🎨 风格目标

我们想把惠农星球的视觉升级为 **中式卡通风格**——温暖、明亮、有农场味。

就像记忆里的 QQ 农场，但又不一样：
- 不是"怀旧"，是"本来就应该这样"
- 圆润的角色，明亮的色彩
- 每个界面都是一幅田园画

这需要找到对的人来做。
